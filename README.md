# End-to-End Customer Sales & Purchase Behavior Analysis Dashboard

An end-to-end Data Analytics project developed using PostgreSQL, SQL, Python, and Power BI to analyze customer purchasing behavior and sales trends. The project transforms raw customer shopping data into meaningful business insights through SQL analysis and interactive dashboard visualizations.

---

## Project Overview

This project analyzes customer purchase behavior by exploring purchasing patterns, product categories, subscription status, seasonal sales, and customer demographics. SQL was used to perform business analysis, while Power BI was used to create an interactive dashboard for decision-making.

- Purchase Amount by Season
- Purchase Amount by Shipping Type

  - Gender
  - Subscription Status

---

## Key Business Insights

- Clothing generated the highest purchase amount among all product categories.
- Most customers were non-subscribers.
- Medium-sized products contributed the highest purchase value.
- Purchase amounts remained relatively consistent across all seasons.
- Customer purchasing behavior varied across categories and shipping methods.
